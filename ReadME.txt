SPICE (Restaurant Website)

A responsive restaurant website project built by following tutorials and applying independent learning.

Key Learnings & Achievements:
->Practiced responsive design using CSS Flexbox and Grid for adaptive layouts.
->Applied box model concepts (margin, padding, border) to achieve clean spacing and alignment.
->Learned to combine multiple CSS properties effectively for visual consistency.
->Implemented semantic HTML tags (<header>, <main>, <nav>, <footer>) for structured content.
->Used <div> and <span> strategically to group and style elements.
->Designed a navigation bar with intuitive links for smooth user experience.
->Experimented with color schemes, typography, and spacing to enhance branding.
->Built a menu section showcasing dishes with concise descriptions.
->Created a visually appealing About Us section highlighting restaurant identity.
->Improved understanding of user-friendly layouts and accessibility principles.
->Practiced responsive scaling for mobile, tablet, and desktop views.
->Learned how to debug and refine CSS/HTML code for better performance.
->Enhanced knowledge of website structure and hierarchy through <nav> and <navbar>.
->Developed confidence in implementing tutorials into real projects with creative adjustments.
->Strengthened ability to conceptualize and execute web projects independently.


This project gave me inspiration to think of new ideas and turn them into reality, motivating further project development.
